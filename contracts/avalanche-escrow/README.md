# Tanko Avalanche Escrow

This contract is the Avalanche C-Chain escrow surface for Tanko fuel payments.
Deploy it to Fuji or Avalanche Mainnet, then set:

```env
NEXT_PUBLIC_AVALANCHE_ESCROW_CONTRACT_ADDRESS=0x...
NEXT_PUBLIC_AVALANCHE_CHAIN_ID=0xa869
```

Use `0xa869` for Fuji and `0xa86a` for Avalanche C-Chain Mainnet.
